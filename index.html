PERSONAL-USE APPLICATION

Private backups.
Verified recovery.

Portfolio Encrypted Backup creates encrypted recovery archives for a private portfolio tracker and stores them in the account owner's Google Drive.

Read the privacy policy →

This website provides application information. The Google Drive connection is being configured.

01

Encrypt locally

Recovery archives are encrypted on the owner's computer. The recovery key stays separate from uploaded files.

02

Store privately

The connection uses an owner-controlled Google Drive folder for encrypted backup objects and their verification receipts.

03

Verify recovery

Before a backup destination is accepted, the application checks file integrity, private access and an isolated recovery.

GOOGLE DATA ACCESS

Access with a
specific purpose.

When connected, the application requests the drive.file scope for files created by or explicitly made available to this application.

Account ownership identifiers, folder and file metadata, access permissions and encrypted contents are used to maintain and verify the owner's backups.

Brokerage access remains read-only. The private dashboard, portfolio records and recovery key are not published on this website.

Questions about access?

Use the support email displayed on this application's Google OAuth consent screen. Read the privacy policy for storage, retention and access controls.
