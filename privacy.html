YOUR DATA & YOUR BACKUPS

Privacy policy

Effective October 21, 2026

Portfolio Encrypted Backup is a personal utility intended for its account owner. This policy explains the Google data used by its backup connection.

Purpose and Google data access

When connected, the application requests the drive.file scope for files created by or explicitly made available to it. It uses account ownership identifiers, backup-folder and file metadata, access permissions and encrypted file contents to store and verify private recovery backups.

Local processing and storage

Portfolio data is encrypted locally before upload. The encrypted payload may contain financial records, source statements and recovery metadata. The encryption key is stored separately and is not uploaded to Google Drive.

Google OAuth tokens and client credentials remain in private local files. They are not included in backups, source repositories or this public website.

Use and disclosure

Google data is used to maintain the owner's backups and verify integrity, permissions and recovery. The application does not sell Google user data, use it for advertising, or use it to train generalized AI models.

Google stores the encrypted objects and associated service metadata under its own terms and privacy policy. The application does not initiate brokerage trades or transfers.

Retention and control

The owner controls backup retention. The application does not automatically delete backup history. The owner can revoke the application's access through Google Account settings and manage stored files through Google Drive. Revoking access does not itself delete existing backups.

This website

These informational pages contain no portfolio data, upload forms, advertising or application analytics. The site is hosted on GitHub Pages. GitHub logs visitors' IP addresses for security purposes, as described in the GitHub General Privacy Statement.

Contact and updates

For questions, use the support email displayed on this application's Google OAuth consent screen. This policy will be updated when the application's Google data practices change; the effective date above identifies the current version.
