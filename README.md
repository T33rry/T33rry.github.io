# Portfolio Encrypted Backup — public application information

This repository contains only the static application homepage and privacy policy
used for Google OAuth branding. It is separate from the private portfolio system.

- `index.html`: application purpose and Google data use
- `privacy.html`: privacy policy
- `styles.css`: local responsive styles
- `.nojekyll`: serve the static files without Jekyll processing

No JavaScript, dependencies, analytics, credentials, backup objects, financial
records or private application source are included. Google authorization and
backup migration are verified separately from this website's deployment.
